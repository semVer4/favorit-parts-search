# Поиск автозапчастей

Тестовое задание: поиск производителей по артикулу, затем предложений и аналогов выбранной детали через API Favorit Parts.

Стек: React, JavaScript, Redux Toolkit, Bootstrap, Vite. Тесты: Vitest и React Testing Library.

## Запуск

Нужен Node.js 24.

```bash
npm ci
npm run dev
```

Приложение откроется по адресу, указанному Vite в терминале. Для проверки можно использовать артикулы `01089` и `7160500039S`.

```bash
npm test
npm run build
npm run preview
```

## Реализация

- Поиск запускается после паузы в 450 мс при вводе или сразу по Enter / кнопке «Найти»
- После выбора производителя отправляется запрос с артикулом, брендом и `analogues=on`
- Цена и остаток берутся из одного элемента `warehouses`, каждое складское предложение выводится отдельно
- Есть обработка пустых результатов, ошибок, отмены и таймаута запроса
- Устаревшие ответы не заменяют результаты нового поиска
- Предложения можно сортировать по цене, фильтровать по наличию и просматривать постранично

Запросы и преобразование данных находятся в `src/api`, состояние — в `src/store`, компоненты — в `src/components`.

## API

[Документация Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf)

Используется HTTPS и публичный пример ключа из документации. Это не личный ключ покупателя; он виден в запросах браузера. Доступность API и лимиты этого ключа зависят от сервиса. Для конфиденциального ключа потребуется серверная прослойка.

## Netlify

Настройки сохранены в `netlify.toml`: Node.js 24, команда `npm run build`, каталог публикации `dist`. Приложение статическое, без серверных функций.
